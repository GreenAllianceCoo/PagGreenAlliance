# Diseño exportado — Green Alliance · Plataforma web

Copia de las pantallas del lienzo de diseño (Claude Design), versión del 23-sep-2026.
Cada pantalla está en dos tamaños: `*-PC.dc.html` (1280 px) y `*-Movil.dc.html` (390 px).
`Main.dc.html` = landing escritorio, `Landing-Movil.dc.html` = landing celular.

Notas:
- Los estilos están en línea: son la referencia exacta de colores, tamaños y espaciados.
- `support.js`, las etiquetas `<dc-import name="Logo">` y las imágenes `/_blob/...` son del editor de diseño y no funcionan fuera de él. Al abrir estos archivos en el navegador el logo y el escudo no se verán; usar los archivos de `public/logos/`.
- Si cambias el diseño, vuelve a exportar las pantallas a esta carpeta antes de llamar a `ga-diseno-a-codigo`.
